This folder contains:
- the hand made masks used to train the software to detect various objects
- a software than can be used to easily hand make the masks (software made with AI assistance and is just a GUI)
- testing scripts to test the detector on random images

Note the detector creating function has been placed out of the folder and is in the neural network folder

Please note that vase detection was attempted however due to the small size of the vases the training was unsuccessful;
this is the reason for the presence of the masks. An attempt was also made to improve the gate detection using the
improved object detection process, but it failed, hence why there are training datas for the gates too.
