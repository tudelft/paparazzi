## Overview
Path planning is a critical component of autonomous drone navigation. It involves determining an optimal path from a starting point to a destination while avoiding obstacles.

## Algorithms

### A* Algorithm
The A* algorithm is a popular pathfinding and graph traversal algorithm. It is widely used due to its performance and accuracy.

### Dijkstra's Algorithm
Dijkstra's algorithm is another well-known pathfinding algorithm that guarantees the shortest path in a graph with non-negative weights.

### RRT (Rapidly-exploring Random Tree)
RRT is a probabilistic algorithm designed for efficiently searching non-convex, high-dimensional spaces by randomly building a space-filling tree.
