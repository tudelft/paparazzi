◆ create_data_demo()

int create_data_demo ( StreamFrameInfo_t * stream_frame_info)

Allocate the vendor capture buffer and host-side image and temperature planes.

Parameters
stream_frame_infoStream state containing buffer sizes and receiving pointers.
Returns
Always 0.

Allocation occurs only when all three pointers are null, preserving a single ownership set and preventing partial replacement while worker threads may be active. The raw buffer must come from the UVC SDK; split planes use the host allocator.

Release capture and split-plane buffers with their matching allocators.

Parameters
stream_frame_infoStream state whose owned buffers will be released.
Returns
Always 0.

The SDK capture buffer is returned through uvc_frame_buf_release(), while image and temperature planes are released with free(). Host pointers are cleared to prevent accidental reuse after stream shutdown.

◆ init_pthread_sem()

int init_pthread_sem ( )

Initialize the one-frame producer-consumer synchronization objects.

Returns
Always 0.

Image and temperature data semaphores start signaled so each consumer can make its initial pass. Done semaphores start unsignaled; after publishing a frame, the producer must wait for both consumers before reusing the shared buffers.
