Detailed Description

Configure CATIA's non-blocking flight-controller UART.

This module owns only the receive-side descriptor setup. Transmit buffering and concurrent writers are handled by serial_tx.c. Raw 8-bit mode is necessary because CATIA frames are binary and can contain bytes that terminal line discipline would otherwise translate or consume.

int serial_init ( const char * port_name)

Configure the shared non-blocking CATIA UART descriptor.

Parameters
port_nameUART device path.
Returns
0 on success or a negative setup error.

The descriptor is set to raw 115200-bit/s 8-bit mode so line discipline cannot translate binary CATIA framing bytes. This module owns descriptor setup only; concurrent transmission must use serial_tx.h.
