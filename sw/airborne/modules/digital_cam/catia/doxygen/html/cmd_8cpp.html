int calculate_org_env_cali_parameter ( )

Reconstruct the environment-correction factors currently used by firmware.

Returns
SUCCESS on success, or FAIL if a property read or factor calculation fails.

Reading EMS, TAU, Ta, and Tu from the module is necessary before host-side correction: their K_E and B_E factors must first be removed to avoid applying two environment corrections to the same measurement.

◆ command_sel()

void command_sel ( int cmd_type)

Execute one interactive camera demonstration command.

Parameters
cmd_typeNumeric command selected by the user.

Several calibration commands intentionally share static arrays: one command reads module state, a later command calculates replacement tables, and another writes them. Run those command sequences in order and do not use them concurrently.

< Inspect correction parameters used by the original firmware method.

< Apply replacement environment parameters using the legacy Tiny correction method.

< Apply the P2 correction model with iterative distance compensation.

< Accept legacy and header-prefixed tau files.

< Read the point temperature currently reported by firmware.

< Remove firmware correction before applying a replacement.

< A second pass refines tau because transmittance depends on target temperature.

◆ read_nuc_parameter()

int read_nuc_parameter ( TempCalInfo_t * temp_cal_info)

Read the active NUC-to-temperature table from module flash.

Parameters
temp_cal_infoCalibration context whose NUC table receives the data.
Returns
FAIL when SPI access fails; otherwise the function currently also returns FAIL.
Warning
The unconditional FAIL return is retained vendor-sample behavior; callers in this sample use the populated table rather than the status value.

Each 16-bit table entry is byte-swapped because SPI storage order differs from the host representation expected by the temperature SDK.

< High-gain table is at 0xDA000; low-gain is at 0xD3000.
