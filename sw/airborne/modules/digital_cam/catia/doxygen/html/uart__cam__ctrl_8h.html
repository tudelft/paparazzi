Detailed Description

Public API for CATIA digital-camera control over UART.

The flight controller sends pose-tagged capture commands to an external camera computer and receives status, thumbnails, or application replies. The API is transport-independent: hardware uses CAMERA_PORT, while simulation targets may use the module-owned local/fallback serial adapter.

See also
modules/digital_cam/uart_cam_ctrl.c for transport ownership and endpoint switching rationale.
