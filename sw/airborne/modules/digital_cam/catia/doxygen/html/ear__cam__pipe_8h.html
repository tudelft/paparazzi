◆ ear_cam_pipe_init()

int ear_cam_pipe_init ( const char * unused)

Allocate session storage and start or configure the acoustic backend.

Start the earcam server. Returns -1 only for configuration errors (missing executable, no memory); a microphone that is not (yet) present is not fatal, the server is restarted periodically from ear_cam_pipe_record().

Returns
-1 only for unrecoverable setup errors; missing hardware stays retryable.

◆ ear_cam_pipe_record()

int ear_cam_pipe_record ( const union dc_shot_union * shot)

Associate the newest fresh acoustic measurement with a camera shot.

Geotag the newest microphone measurement with a shot message.

Returns
0 when appended, -1 when no current measurement is safe to use.

The session discards its oldest half at capacity, retaining recent location evidence while bounding memory for unattended multi-day operation.

Render the current acoustic session into a north-up JPEG before it is cleared.

Render the current session as an acoustic "photo" photos/e%06d.jpg (north-up intensity map with the loudest spot marked). Fills filename; returns 0 on success. Must be called before ear_cam_pipe_finish() clears the session.
