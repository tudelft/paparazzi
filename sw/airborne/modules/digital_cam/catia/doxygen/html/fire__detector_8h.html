Detailed Description

Thermal-fire candidate selection layered on generic hotspot extraction.

Candidate ranking combines absolute temperature, scene-relative contrast, local background, connected-region geometry, and optional tray-like target heuristics. Keeping each metric in the result makes field tuning auditable rather than opaque.
