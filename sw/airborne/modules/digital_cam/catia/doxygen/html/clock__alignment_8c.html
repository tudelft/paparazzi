Detailed Description

Implementation of CATIA's token-bound, interval-based clock alignment.

This intentionally avoids synchronizing clocks globally. It validates a small request/reply exchange, then maps only poses that carry the matching token. Integer interval arithmetic makes the drift assumptions explicit and handles normal uint32_t flight-controller timer wrap by subtraction.
