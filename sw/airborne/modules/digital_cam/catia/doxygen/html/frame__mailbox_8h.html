Detailed Description

Latest-frame handoff between the vendor USB callback and capture logic.

A one-slot mailbox intentionally favors freshness over completeness: a slow consumer may miss intermediate video frames, but a requested photograph must use the newest frame arriving after its request timestamp. The callback uses trylock so USB delivery is never blocked by JPEG encoding or stability analysis.
