Detailed Description

Bounded asynchronous CSV recorder for flight-controller pose evidence.

The UART path uses trylock and drops rather than blocks when the writer is busy. A dedicated thread batches durable writes, preserving acquisition latency while recording queue loss and clock-alignment provenance explicitly in each row.
