Detailed Description

Bounded mutex-protected output queue for CATIA UART frames.

Writes are non-blocking and may be partial. The ring buffer retains the unsent suffix until the main event loop sees POLLOUT. A permanent write failure is latched instead of silently dropping later messages, allowing CATIA to exit and let systemd recover the UART connection.

Flush as much queued output as the descriptor currently accepts.

Precondition
transmit_mutex is held.
Returns
0 for success or temporary backpressure, -1 for a latched terminal error.

EAGAIN/EINTR deliberately retain the ring contents. Other errors are retained in output_error so the owning event loop can surface the failure.

◆ serial_tx_pending()

bool serial_tx_pending ( void )

Report queued data or a latched output error needing event-loop handling.

Returns
True while the event loop should request POLLOUT and call serial_tx_flush().

Once set, output_error never clears itself; also report pending when it is set (even with an empty queue) so the caller's poll loop keeps asking for POLLOUT and promptly calls serial_tx_flush(), which surfaces the failure instead of leaving UART output silently and permanently stuck.
