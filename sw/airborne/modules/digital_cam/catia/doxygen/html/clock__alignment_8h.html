Detailed Description

Bounded mapping between flight-controller microseconds and CATIA monotonic time.

The protocol exchanges a random token and controller receive/transmit times. The resulting interval is deliberately bounded, short-lived, and token-associated so stale replies or a wrapped 32-bit controller clock cannot geotag audio with false precision.
