int ear_heatmap_write ( const char * filename,
const struct ear_sample * samples,
size_t count,
const struct ear_loudest_spot * spot )

Render the geotagged samples as a north-up acoustic intensity map. Ground resolution follows the microphone footprint (about AGL/4 per cell); the fused loudest spot is drawn as a marker. Writes filename and returns 0.
