Detailed Description

Loopback UDP implementation for CATIA's local development transport.

The fixed port permits the local bridge and test tools to find each other without configuration. All I/O is non-blocking so local consumers cannot delay the flight-controller UART event loop.

◆ socket_init()

int socket_init ( int is_server)

Create the loopback UDP endpoint and, for a server, claim CATIA ownership.

Parameters
is_serverNonzero to bind the fixed local port; zero for an unbound sender.
Returns
0 on success or -1 when socket creation/binding fails.

The server bind doubles as the physical-mode single-instance claim. A second CATIA must fail rather than share the port because it would also compete for the same UART and camera resources.
