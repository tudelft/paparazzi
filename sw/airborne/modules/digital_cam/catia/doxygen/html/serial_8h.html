Detailed Description

Legacy UART descriptor setup and byte-oriented compatibility macros.

New CATIA code should use serial_tx.h for output because it preserves frame boundaries under concurrent worker activity. The macros remain for platform compatibility with the historic transport interface.

◆ serial_init()

int serial_init ( const char * port_name)

Configure the shared non-blocking CATIA UART descriptor.

Parameters
port_nameUART device path.
Returns
0 on success or a negative setup error.

The descriptor is set to raw 115200-bit/s 8-bit mode so line discipline cannot translate binary CATIA framing bytes. This module owns descriptor setup only; concurrent transmission must use serial_tx.h.
