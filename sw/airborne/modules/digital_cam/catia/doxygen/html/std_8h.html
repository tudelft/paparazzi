Detailed Description

Compatibility transmit primitive for legacy CATIA framing macros.

Modern concurrent CATIA paths use serial_tx.h. This primitive remains for macros shared with the historical protocol layer and bounds backpressure to one second so a disconnected peer cannot deadlock the process.
