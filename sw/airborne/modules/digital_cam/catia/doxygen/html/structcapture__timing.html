Detailed Description

Correlated request and frame-delivery evidence for one LWIR capture.

A non-callback capture has no callback sequence evidence. A callback-backed capture must provide a strictly later arrival timestamp and a nonzero sequence number, so consumers can distinguish a fresh frame from a stale parser result.
