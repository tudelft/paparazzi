Detailed Description

Persistent state for incremental CATIA UART frame parsing.

One instance must remain associated with one ordered byte stream. A completed message remains in payload until its consumer clears msg_received; feeding later bytes before that acknowledgement is counted as an error to avoid silently overwriting it.
