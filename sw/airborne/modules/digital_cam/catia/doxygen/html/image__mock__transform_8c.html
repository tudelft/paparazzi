◆ image_mock_transform()

int image_mock_transform ( const char * filename,
const union dc_shot_union * shot )

Rewrite a local test JPEG to simulate the shot attitude.

Parameters
filenameWritable path to the JPEG to transform in place.
shotFlight pose containing fixed-point roll, pitch, yaw, and position fields.
Returns
IMAGE_MOCK_TRANSFORM_APPLIED, IMAGE_MOCK_TRANSFORM_SKIPPED, or -1 on failure.

The transform uses a perspective projection and an atomic temporary-file rename so consumers never observe a partial JPEG. Near-horizon frames are skipped or synthesized by configured policy because planar image projection becomes numerically untrustworthy there.

Warning
This is simulation evidence only; it does not model a calibrated physical camera.
