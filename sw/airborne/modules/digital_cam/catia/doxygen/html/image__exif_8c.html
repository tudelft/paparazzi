Detailed Description

Atomic JPEG EXIF rewriting for CATIA flight and thermal-capture provenance.

Existing JPEG markers are copied while prior EXIF is replaced by a standards compliant APP1 block. A temporary sibling file plus fsync/rename prevents consumers from observing a partially rewritten capture after power loss or storage failure.
