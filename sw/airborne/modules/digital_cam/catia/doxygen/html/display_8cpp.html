Parameters

Two RGB-sized buffers support conversion and orientation operations without modifying the producer-owned image plane. Missing ffplay is nonfatal because capture and temperature processing remain useful in headless deployments.

Apply SDK Y14 enhancement or copy the source unchanged.

Parameters

frameinfoFrame dimensions and enhancement selection.
dst_frameDestination with room for one 16-bit value per pixel.
Returns
0 on success, or -1 when dimensions exceed the SDK's 16-bit limits.

Temperature-aware enhancement uses a 10 to 35.5 degree Celsius window, encoded in the SDK's Kelvin Q4 representation. This emphasizes common scene temperatures while leaving enhancement optional for quantitative workflows.
