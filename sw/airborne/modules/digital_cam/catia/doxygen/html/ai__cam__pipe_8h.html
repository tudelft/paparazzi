Release backend state; currently a no-op because captures are synchronous.

rpicam-still is owned and reaped synchronously by ai_cam_pipe_shoot(), so this adapter has no persistent process or descriptor to release.

int ai_cam_pipe_shoot ( char * filename,
size_t filename_size,
int image_number )

Capture a JPEG with rpicam-still.

Parameters
filenameOutput path buffer, cleared on failure.
filename_sizeOutput path capacity.
image_numberCATIA shot number.
Returns
0 only for a verified output file; otherwise -1.

A hung rpicam-still must not block this worker thread (and, once all worker slots fill with the same hang, the entire capture pipeline) forever: wait with a bounded deadline and kill it if exceeded, so the shot fails fast and the next one can retry.
