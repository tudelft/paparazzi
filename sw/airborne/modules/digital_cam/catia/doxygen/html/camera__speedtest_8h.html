Atomically create a private directory for one benchmark run.

Parameters

output_sizeCapacity of output.
Returns
0 on success, otherwise -1 with errno set.

A private mode-0700 directory prevents benchmark backends, which normally replace same-number files, from racing with or overwriting mission photographs.

Find an unused consecutive image-number block for warm-up and samples.

Parameters
configBackend filename information.
first_imageReceives the warm-up image number.
Returns
0 on success, -1 on invalid input, filesystem error, or exhausted range.

CATIA camera backends replace an existing same-number image. Preflighting the complete block before camera initialization keeps benchmark evidence separate from mission captures and prevents accidental replacement of an existing photo.

◆ camera_speedtest_run()

int camera_speedtest_run ( const struct camera_speedtest_config * config,
int first_image )

Capture one untimed warm-up image and ten timed images sequentially.

Parameters
configSelected and initialized camera backend.
first_imageWarm-up image number returned by camera_speedtest_find_image_block().
Returns
0 only when every requested image was captured and validated.

Only synchronous shoot time is used for camera throughput. Progress records are written through bounded nonblocking I/O by a separate reporter thread, so a slow terminal cannot delay capture requests or inflate measured camera latency. Images are retained for review.
