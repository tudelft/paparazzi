Detailed Description

Read Linux's boot-unique identifier for pose-log session provenance.

A boot ID distinguishes monotonic timestamps from two daemon runs after a board reboot. Failure is nonfatal and intentionally represented as "unknown" so logging remains available on non-Linux development systems.
