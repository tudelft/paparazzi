int calculate_new_env_cali_parameter ( uint16_t * correct_table,
double ems,
double ta,
double tu,
double dist,
double hum )

Build host-side correction factors for a new measurement environment.

Parameters
correct_tableAtmospheric transmittance table matching the active gain mode.
emsTarget emissivity in the range 0.01 to 1.0.
taAtmospheric temperature in degrees Celsius.
tuReflected ambient temperature in degrees Celsius.
distTarget distance in meters, in the range 0.25 to 49.99.
humRelative humidity as a fraction in the range 0.0 to 1.0.
Returns
0 on success, or -1 if transmittance lookup or factor calculation fails.

The SDK expects fixed-point environment values. Converting them here keeps later temperature recalculation consistent with the module's NUC table.

Convert a frame of fixed-point temperatures back to raw NUC values.

Parameters
org_tempInput temperatures encoded as Kelvin multiplied by 16.
nuc_factorQuadratic mapping coefficients for the active calibration.
pix_numNumber of pixels to convert.
nuc_dataOutput buffer with room for pix_num NUC values.
Returns
0 on success, or -1 when any SDK reverse-mapping operation fails.

Recovering NUC values removes the existing environment correction so a different correction model can be applied without acquiring another frame.

Recalculate one temperature using a new set of environment factors.

Parameters

void * temperature_function ( void * threadarg)

Consume temperature frames and periodically report a representative measurement.

Parameters
threadargPointer to the shared StreamFrameInfo_t instance.
Returns
Always NULL when the worker exits.

The worker reports every 25th frame to keep terminal output readable. It posts temp_done_sem after each frame so the producer may safely reuse the shared temperature buffer without racing this consumer.

< Sample periodically because full-rate logging would obscure command output.
