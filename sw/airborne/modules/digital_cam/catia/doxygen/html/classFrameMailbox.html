Detailed Description

Thread-safe latest-frame mailbox with monotonic deadline waits.

Warning
Instances are non-copyable because mutex/condition ownership cannot be duplicated safely.

Wait for the newest frame meeting a request timestamp and copy it out.

Parameters
destinationStable caller-owned output buffer.
bytesExact mailbox size.
stampIn/out last observed stamp; newer evidence replaces it.
not_before_usRequire a frame that arrived strictly after this time.
deadline_usAbsolute monotonic deadline.
Returns

The mutex protects frame bytes and stamp as one coherent snapshot.
