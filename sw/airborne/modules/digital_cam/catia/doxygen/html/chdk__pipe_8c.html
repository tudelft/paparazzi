Detailed Description

Persistent CHDKPTP controller-process adapter for legacy visible cameras.

CATIA drives the controller through stdin/stdout pipes and parses its prompt protocol with operation-wide deadlines. Buffered reads reduce syscall overhead while keeping the original response framing semantics. Any command failure clears the returned filename, allowing CATIA's backend lifecycle to retry on a later shot.
