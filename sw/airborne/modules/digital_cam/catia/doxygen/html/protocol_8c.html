Detailed Description

Incremental parser for CATIA's UART framing protocol.

The UART transport is a byte stream, so this parser keeps state across calls and accepts arbitrarily fragmented frames. It validates both Fletcher-style checksum bytes before publishing a message. On malformed input it discards only the current partial frame and resumes searching for the next start byte; this is deliberately resilient to line noise and lost bytes.

void parse_catia ( struct catia_transport * t,
uint8_t c )

Consume one UART byte and advance a CATIA transport parser.

Parameters
tPersistent parser state owned by the receiving transport.
cNewly received byte.

Checksums cover the length, message ID, and payload bytes. A complete, valid frame sets t->msg_received; the caller must clear that flag after dispatching. Any framing or checksum error increments t->error and resets the state machine, avoiding a poisoned partial frame affecting later traffic.

Warning
t must remain valid and unchanged by another thread for the duration of a frame; this parser intentionally contains no synchronization.
