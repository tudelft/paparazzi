Detailed Description

Small path and writable-directory helpers shared by CATIA backends.

Paths are intentionally resolved only for a leading ~: CATIA configuration is not a shell and must not expand arbitrary variables or execute shell syntax.

int catia_ensure_directory ( const char * path)
inlinestatic

Create missing directory components and verify the final directory is writable.

Parameters
pathDirectory path, with optional leading home shorthand.
Returns
0 for a writable directory, otherwise -1.

Components are created one at a time to avoid invoking a shell. Existing parents are harmless, while final stat/access checks distinguish a file or read-only path from a usable capture destination.
